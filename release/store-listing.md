# multipleX 申請用文面

## 詳細説明

multipleX（マルチプレックス）は、Xのホームタイムラインを4列で表示する非公式の拡張機能です。

- 投稿を4列に配置し、4列まとめてスクロールできます。
- 親ポストとつながるリプライを同じ列で縦に表示します。
- ホームタイムラインの広告投稿と右サイドバーを非表示にします。
- 投稿の三点メニューを「このポストに興味がない」ボタンに置き換えます。クリックするとXの同名のメニュー操作を実行します。
- 拡張アイコンから自動スクロールを開始・停止できます。速度は10〜300px/秒、10px/秒刻みで調整できます。

自動スクロールは操作したタブのみが対象です。非表示タブでは一時停止し、ホーム以外への移動やページの再読み込みで停止します。

Xのホームタイムラインを開いて使用してください。表示変更はホーム画面のみが対象です。Xの画面仕様の変更により動作しなくなる場合があります。

X Corp.が提供・承認する製品ではありません。

## 単一の目的

Xのホームタイムラインを4列に再配置し、表示整理とスクロール操作の補助により閲覧しやすくすること。

## x.comへのアクセスが必要な理由

ホームタイムラインの投稿・返信・広告をページのDOMから判別して表示を変更し、ユーザーが選んだ「興味がない」操作と自動スクロールを実行するためです。Xの他の画面からホームへのページ内遷移にも対応するため、コンテンツスクリプトをhttps://x.com/*で読み込みます。ホーム以外では機能を停止します。

## リモートコード

使用していません。本番機能のJavaScriptとCSSはすべて拡張パッケージに含まれています。

## 審査用操作手順

1. Xにログインした状態で https://x.com/home を開きます。Xアカウントが必要です。
2. 投稿が4列に表示され、ページ全体をスクロールできることを確認します。
3. 拡張アイコンを押し、自動スクロールの開始・停止と速度調整を確認します。
4. 「興味がない」ボタンはXへのフィードバック送信を伴います。審査用アカウントの投稿で確認してください。
5. プロフィールなどホーム以外では通常表示になります。

- ストア用スクリーンショットと必要な紹介画像を用意する。本人のアカウント情報が写った画像をそのまま公開しない。
