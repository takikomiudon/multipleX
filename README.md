# multipleX

Xのホームタイムラインを4列に並べるChrome拡張です。
左から右、上から下の順に投稿が並び、ページのスクロールで4列が一緒に動きます。
ホームの右サイドバーは非表示になります。投稿ボタンや配色はXのものを使います。

## 読み込み

1. Chromeの `chrome://extensions`（Braveでは `brave://extensions`）を開く。
2. 「デベロッパーモード」を有効にする。
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選ぶ。
4. Xのホームを再読み込みする。

ビルド・APIキー・外部ライブラリは不要です。
ホーム以外からの画面遷移にも対応するため、スクリプトの対象は `https://x.com/*`、表示変更は `/home` のみです。
拡張の構成は[Chrome公式のcontent_scripts仕様](https://developer.chrome.com/docs/extensions/reference/manifest/content-scripts)に従っています。

## テスト

```sh
node content.test.cjs
node layout.test.cjs
python3 -m http.server 8765 --bind 127.0.0.1
```

`http://127.0.0.1:8765/test.html` をブラウザで開くと、4列配置、重なり、横幅、共通スクロール、追加投稿、仮想スクロール、ホーム限定のレイアウト検証を実行します。

Xの投稿は仮想スクロールで絶対位置に配置されます。拡張は4投稿の高さを測り、各投稿がスクロール計算上で占める高さを行の高さの1/4にします。元の移動量・追加取得を保ちながら、内容を同じ行に並べます。

2026-09-10にBraveの実際のXで確認済み:

- おすすめで10,000px以上のスクロールと投稿の追加読み込み。
- 4列それぞれの実投稿が同じ1,200px移動すること。
- 上方向に戻った際の再表示と投稿の重なりがないこと。
- フォロー中の4列表示と追加読み込み。
- 「さらに表示」で長文を開いた後の行の高さの再計算。
- プロフィールでは通常表示になり、戻る操作でホームの4列表示が復元すること。

XのDOM構造が変更された場合は追従が必要です。Chrome単体での実機確認は未実施です。
